# Private reviewer rubric — never supplied to authors

Use these IDs and this order:

| ID | Required content |
|---|---|
| O1_PROTOCOL_CAUSALITY | A concrete transcript recursion and causal presentation rule for an arbitrary deterministic optional-one-query generator, in presentation/query/answer/output order. |
| O2_PARTIAL_ASSIGNMENT_TARGET | Concrete consistent monotone ordinary IN/OUT states; one fixed limit target in the exact class; and the sample-free positive clause. |
| O3_FIXED_TARGET_REPLAY | Recursive feedback is truthful for that one limit target, and the construction satisfies the fixed generator's actual query and output equations; equivalent truthful-protocol/uniqueness formulations are allowed. |
| O4_CLEAN_INJECTIVE_COMPLETE_PRESENTATION | The constructed presentation is causal, clean, injective, and has range exactly the limit target. |
| O5_ADMITTED_SET_POSITIVE_DENSITY | Quantitative estimates derived from the construction, giving positive admitted ambient density and a linear bound for increasing target ranks; any valid sufficient positive constant is acceptable. |
| O6_SCORED_OUTPUTS_IN_SPARSE_CORE | Concrete output reservation implies that every distinct scored target point lies in the powers-of-two core. |
| O7_TARGET_RELATIVE_ZERO_DENSITY | Instantiate the sparse-core count and target-order bounds to prove the actual scored set has upper density zero and assemble the generation claims. |
| C1_CLASS_UNCOUNTABILITY | Prove that the exact extensional class `Stage3S2B.targetClass` is not countable. |

These items characterize partial progress, not a prescribed proof route.
The reviewer, not the author, records PROVED / PARTIAL / BLOCKED / UNCERTAIN
with exact supporting declarations, established assumptions, and the first
substantive gap. A compiling conditional statement does not construct its
hypotheses. Recognize alternative routes explicitly. Do not rank by a raw
count of covered items; describe the checked dependency chain and distinguish
missing core construction from interface work or final technical cleanup.
