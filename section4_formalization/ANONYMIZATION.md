# Historical anonymization record

This release module was produced from the formalization working repository for
double-blind review.

Excluded from this copy:

- the source repository's `.git` directory, remotes, branches, and commit log;
- private manuscript/Overleaf synchronization records;
- author-named human-audit records and unrelated whole-library registry data;
- pull-request templates and repository-specific GitHub automation;
- local build products, caches, editor metadata, and credentials.

Direct links to author-controlled repositories and identifying source revisions
were withheld in the review snapshot. Public author and library information is
now given in README.md; omitted private history has not been restored. Scholarly citations to third-party publications,
mathematical source attributions, and public toolchain dependencies are retained.

The Lean source files used by the Section 4 build are unchanged. Release-only
documentation and the verification wrapper were sanitized so the module can be
checked without access to the original Git history.
